# Network scores: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the network parts of SeedMatchR to `seedmatch.network`. The scores obey the corrected rules of `D-007`, not the R values. These are the parts:

- the TRRUST table of `get_network_matches`, and the messages of `message_passing`
- the STRING links of `get_stringPPI_to_stringGGI`, and the map from the STRING protein IDs to the gene IDs
- the seed counts of `create_graph`

**Architecture:** `seedmatch.network` is a package with these modules:

- `messages.py`: `Aggregator`, and the mean of the messages of each gene.
- `trrust.py`: `read_trrust` and `trrust_scores`.
- `stringdb.py`: `read_string_links`, `StringLinks`, `string_gene_network`, `GeneNetwork`, and `string_scores`. The ruff rule `A005` does not let a module have the name `string`, because the standard library has a module `string`.

A network is a `DataFrame` of edges, not a graph object. `np.bincount` sums the messages of each gene, thus the port uses no graph library. A caller who wants a graph can give the edges to a graph library. The word `network` in the package name means a gene network. The package does not use the internet, and the rule `TID251` applies to it as to each core module.

The readers of the TRRUST and STRING files use the line helpers of `seedmatch.mirdb`. Task 2 moves these helpers to `seedmatch._lines`, without a change of a message. `AnnotationDb.protein_genes` reads the `protein` table of an EnsDb. `seedmatch._rmath.r_quantile` gives the type 7 quantile of R with the arithmetic of R.

**Tech Stack:** Python 3.12, numpy, pandas, and `sqlite3`. R 4.5.3 with igraph 2.3.3, Matrix 1.7.5, DBI 1.3.0, RSQLite 3.53.3, and SeedMatchR 2.0.0 for the goldens. STRINGdb and biomaRt are not in `tools/golden/.rlib`. The golden script replaces them with functions that read the local files.

**Spec:** `docs/design.md`, sections "Architecture", "Divergences (defect fixes)", "Performance and bounds", and "Calls of the designer" (the EnsDb `protein` table maps the STRING protein IDs).

**Later plans (not in this plan):**

- The plot of a network (delivery step 9).
- A `protein` table for a GTF reference. The Ensembl GTF has a `protein_id` attribute on each CDS line, but `load_gtf` does not read it. Thus `string_gene_network` raises `InputError` for a GTF reference.

Rules of the line helpers:

- `read_chunks` yields the number of the first line of each chunk and its lines. A line keeps its line end. `handle.readline(LINE_LIMIT + 1)` reads each line after line 1, thus a longer line comes as parts of `LINE_LIMIT + 1` characters without a line end. Line 1 reads with the limit `LINE_LIMIT + 2` and then loses a byte order mark, because the mark can take one character of the limit. The handle does not have to be seekable.
- `read_chunks` and `field_lines` raise `ValueError` for a `chunk_lines` below 1 and for a `fields` below 2.
- `field_lines` returns `True` for each line with `fields - 1` separators. A blank line gets `False`. A line of more than `LINE_LIMIT` characters raises the long-line message of `seedmatch.mirdb`. A line with another count raises `'<source>': line <n> has <count> field(s); expected <fields>: <described>`.
- `data_bytes` joins the data lines and encodes them in UTF-8. A NUL character raises the NUL message of `seedmatch.mirdb`, with the number of its line.
- `not_utf8` returns `InputError('<source>': the file is not valid UTF-8 text (<reason>); expected a text or gzip <kind> file)`.
- `vocabulary_codes` and `shared_texts` are `_vocabulary_codes` and `_shared` of `seedmatch.mirdb`. `frame_of` makes the `DataFrame` of `_Rows.table`, with a `Series` of the dtype of each array and no copy.

`mean_messages` gives, for each gene g, the number of senders and the score. Let S(g) be the senders of g, f the values, and w the weights. The score is (Σ over s in S(g) of w(s) · f(s) / |S(g)| + f(g)) / 2. A gene without a sender has the score NaN.

The function uses `np.bincount` with `minlength=len(values)`, thus the time is O(E + G) for E edges and G genes. `sender_weights` gives 1 for `MEAN`, and 1 / `out_degree` for `DEGREE_IMPORTANCE`. A gene with the out-degree 0 sends no message, thus its weight is 0.

Rules of `check_text_columns`:
- The first value of the columns `names` that is not a `str` raises `<label> column 'source' holds 5 in row 2; expected a str in each row`. The row is the position. `None` and NaN are not a `str`, thus NaN gives `holds nan`.

Rules of `read_trrust`:
- The path is a local path. A URL raises the message of `local_path`. `open_text` reads text, gzip, bzip2, or xz.
- The file has no header. Each line has 4 fields with a tab between them. The result has the columns `source`, `target`, `edge_type`, and `evidence`, the names of `R/get_network_matches.R:30`. These inputs raise `InputError`:
- A line with another number of fields: `'<path>': line 3 has 3 fields; expected 4: the regulator, the target, the mode, and the PubMed IDs`.
- A mode other than the members of `TRRUST_MODES`: `'<path>': line 2: mode 'activation' is not valid; expected Activation, Repression, or Unknown` (`D-057`).

Rules of `trrust_scores` (`D-007`):
- `network` goes through `check_columns(network, ("source", "target", "edge_type"), name="network", label="TRRUST table")`. Then `check_text_columns` with the same names and the label `TRRUST table`. A table without a row raises `the TRRUST table has no row; expected at least one edge`.
- A mode outside `TRRUST_MODES` raises `TRRUST table column 'edge_type' holds 'activation' in row 0; expected Activation, Repression, or Unknown`. The column `evidence` is optional.
- `seed_genes` goes through `as_items("seed_genes", seed_genes, as_text, "str")`, thus a `str` raises `seed_genes 'TFA' is a str; expected a sequence of str, for example ('TFA',)`.
- `aggregator` goes through `as_member`: `aggregator 'mean' is not valid; expected one of Aggregator.MEAN, Aggregator.DEGREE_IMPORTANCE`.
- The genes are `pd.factorize(pd.concat([source, target]))`. Thus the order is the order of the first occurrence of each gene, the vertex order of `graph_from_data_frame`.
- The seed flag of a gene is 1 if the gene is in `seed_genes`, and 0 otherwise. A seed gene that is not in the network has no effect.
- An edge is a distinct (`source`, `target`, `edge_type`) triple. A `Repression` edge is in the repression channel, and an `Activation` edge is in the activation channel. An `Unknown` edge is in no channel.
- Thus a pair with two modes is in each channel of its modes, and a triple on more than one line counts one time. A line with a gene as its own regulator makes the gene its own regulator.
- The out-degree of a regulator is the number of its distinct targets, over each mode, also `Unknown`.
- The scores of each channel come from `mean_messages`. The receivers are the targets, the senders are the regulators, and the values are the seed flags. The weights come from `sender_weights(aggregator, out_degree)`.
- A gene that is a regulator and a target gets its scores only from its own regulators.
- A gene without a regulator in a channel gets NaN for the score of this channel.
- If no gene of `seed_genes` is a gene of the network, warn with `SeedMatchWarning` (`D-058`). The message is `no gene of seed_genes is a gene of the TRRUST table; each seed flag is 0. TRRUST names a gene by its symbol, for example 'TFA'`. The example is the first gene of the network.
- The result has one row for each gene, and a `RangeIndex`. Its columns are `gene` (`object`), `seed` (`bool`), `repressors` (`int64`), `repression_score` (`float64`), `activators` (`int64`), and `activation_score` (`float64`).
- The time is O(R log R) for R rows, because `np.unique` sorts the edge keys. The memory is O(R + G).

Rules of `r_quantile`:
