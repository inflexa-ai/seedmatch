# Map from R names to Python names

This table maps each SeedMatchR function to its Python replacement. If a column gets a new name or a value gets a new type, this table records the change. Such a change is not a divergence. A change of behavior goes in `docs/divergences.md`.

| R function | Python | Notes |
| --- | --- | --- |
| `Biostrings::readDNAStringSet` | `seedmatch.sequence.read_fasta` | Returns a `SequenceSet`. The ID of a record is the header text up to the first white space (`D-016`). The reader changes lowercase letters to uppercase. A letter that is not an IUPAC DNA letter raises `InputError`. R accepts `-`, `+`, and `.`, but the port does not (`D-017`). |
| `Biostrings::reverseComplement` | `seedmatch.sequence.reverse_complement` | Takes and returns a `str`. The result has uppercase letters. Each IUPAC DNA letter has its complement, so `YYAYAGAG` gives `CTCTRTRR`, as in R. A letter that is not an IUPAC DNA letter raises `InputError` (`D-017`). |
| `get_seed`, `.get_canonical_seed`, `.get_custom_sequence` | `seedmatch.Guide.target` | `Guide(sequence)` holds the guide as uppercase RNA. `Guide.target(seed, wobble=False)` returns a `Target` with the fields `name`, `sequence`, and `seed_rna`. `sequence` is `Target.Seq` of R, and `seed_rna` is `Seed.Seq.RNA`. A `Seed` member replaces a canonical `seed.name`. A `CustomSeed(name, start, stop)` replaces `seed.name` with `start.pos` and `stop.pos`. `wobble` replaces `allow_wobbles`. A guide that is too short for the seed raises `InputError` that names the seed and the length. R stops with `nchar(guide.seq) >= 8 is not TRUE` or `stop.pos <= nchar(guide.seq) is not TRUE`. A lowercase guide gets the wobble (`D-018`). The guide takes only `A`, `C`, `G`, and `U` (`D-019`). A `CustomSeed` with `start` after `stop` raises `InputError` (`D-020`). |
| `Biostrings::vcountPattern` | `seedmatch.count_matches` | Takes a pattern (a `str` or a `Target`), a `SequenceSet`, and a `SearchOptions`. Returns an `int64` array with one count for each sequence. `max.mismatch`, `min.mismatch`, and `with.indels` become `max_mismatch`, `min_mismatch`, and `indels` of `SearchOptions`. The two entries of `fixed` become `fixed_pattern` and `fixed_subject`. The default of `indels` is `False`, as in Biostrings, but `SeedMatchR` has the default `with.indels = TRUE`. An empty pattern raises `InputError`, and so does a letter that is not an IUPAC DNA letter (`D-017`). |
| `Biostrings::vmatchPattern` | `seedmatch.find_matches` | Returns a `pandas.DataFrame`, not an `MIndex`. One row is one match. The columns are `seq_id`, `gene_id`, `start`, `end`, and `width`. The rows come in the order of the sequences. A mismatch match can start before 1 or end after the sequence length, as in R. The options are the options of `count_matches`. `vmatchPattern` stops for a `DNAStringSet` with `with.indels = TRUE` and `max.mismatch > 0`, but `find_matches` does not (`D-001`). |
| `vmatchPattern2` | `seedmatch.find_matches` | The R data frame has the columns `start`, `end`, `width`, and `names`. `seq_id` replaces `names`, and `gene_id` is new. A sequence without a match has no row, as in R. The ranges obey `indels` and `min_mismatch` (`D-001`). |
| `filter_res` | `seedmatch.filter_de` | Takes a `DataFrame` and returns a new `DataFrame` with a new index. `res` becomes `de`. The cutoffs `fdr_cutoff`, `fc_cutoff`, and `basemean_cutoff` have the R names and the R defaults, but they are keyword-only. The result keeps the order of the rows. A row with a missing `padj`, `pvalue`, `log2FoldChange`, or `baseMean` is removed. A table without a required column raises `InputError` that lists the missing columns in sorted order. R stops with `"padj" %in% colnames(res) is not TRUE`. A filter column with a dtype that is not numeric raises `InputError` that names the column and the dtype. |
| `download_parse_file` | `seedmatch.read_deseq2_table` | Reads a table from a path, because the core modules do not use the network. The file can be gzip. The function replaces the header with the DESeq2 column names `gene_id`, `baseMean`, `log2FoldChange`, `lfcSE`, `stat`, `pvalue`, `padj`, and `symbol` (`R/get_data.R:74-76`). `gene_id` and `symbol` are text, and the other columns have the type `float64`. R reads a column of digits as numbers, but the port reads `gene_id` as text. As in `read.csv`, only `NA` is missing in a text column, and `NA` or an empty field is missing in a number column. A table that does not have exactly 8 columns raises `InputError` that gives the count found (`D-021`). These tables also raise `InputError`: an empty file, a row with more fields than the header, and a number column with a value that is not a number. |
| `SeedMatchR` with `res.format = "DESEQ2"` | `seedmatch.annotate_seed_counts` | `res` becomes `de`, and `seqs` becomes `sequences`. A `Target` replaces `sequence` and `seed.name` (`Guide.target`). `col.name` becomes `column`, and the default is the name of the target. `max.mismatch`, `with.indels`, and `fixed` become `options`. The default is `SearchOptions(indels=True)`, the search with the R defaults. `shared_genes` keeps its meaning. The result keeps the rows of the genes with a sequence, in the order of the input, and has a new index. The function returns a new `DataFrame` and does not change `de`. The count column has the type `int64`, but R gives a `double`. The count of a gene is the maximum over its sequences (`D-003`). A column with the same name is replaced (`D-015`). A `de` without a `gene_id` column raises `InputError`. A `gene_id` column that is not text raises `InputError`, because no gene would match. `column` cannot be `gene_id`. |
| `full_search` with `res_format = "counts"` | `seedmatch.full_search` | `guide.seq` becomes a `Guide`, `seqs` becomes `sequences`, and `group.name` becomes `group`. The other arguments become the fields of `FullSearchOptions`, and the defaults are the R defaults. `seqs.to.search` becomes `seeds` (a tuple of `Seed`). `nonseed.edit.distances` and `seed.edit.distances` become `nonseed_edit_distances` and `seed_edit_distances`. `indel.bool` becomes `indels`, and `allow_wobbles` becomes `wobble`. `fixed` becomes `fixed_pattern` and `fixed_subject`. These are off by default, unlike in `SearchOptions`. R passes `with.indel` (a partial name) to `vcountPattern` (`R/full_search.R:61`), and Biostrings reads it as `with.indels`. The keyword `workers` sets the width of the thread pool, and the result does not depend on it. The count columns keep the R names `<seed>.mm<distance>` and have the type `int64`. `seqs`, `Group`, and `best.match` become `seq_id`, `group`, and `best_match`. A new column, `gene_id`, follows `seq_id`. `FullSearchOptions` raises `InputError` for an invalid option, for a duplicate value (`D-023`), and for a set instead of a tuple or a list. A guide that is too short for a seed raises `InputError` that names the seed and the length, before any search. `res_format = "iranges"` has no counterpart. `full_search_ranges` does not replace it, because the functions differ. The `iranges` mode of R uses `allow_wobbles`. It takes the separate lists `nonseed.edit.distances` and `seed.edit.distances` and the flag `indel.bool`. It names a search `<seed>.mm<distance>`, without an indel flag. Its columns are `start`, `end`, `width`, `names`, `query`, and `Group`. Its rows go by seed first, then by distance. `full_search_ranges` has no wobble option. It takes a list `edit_distances` with the limit `max_seed_edit_distance`, and a list `indel_options`. Its rows go by distance first, then by seed, then by flag. To get the `iranges` result, call `find_matches` for each seed and distance, with a target from `Guide.target`. |
| `full_search_ranges` | `seedmatch.full_search_ranges` | The arguments `indel.bool.opt`, `edit.dist.list`, `seqs.to.search`, `fixed.opt`, and `max.seed.edit.dist` become `indel_options`, `edit_distances`, `seeds`, `fixed_pattern` and `fixed_subject`, and `max_seed_edit_distance` of `FullSearchRangesOptions`. The rows follow the `expand.grid` order of R. The ranges obey `indels` (`D-001`). `seqnames`, `TargetSeq`, `EditDistance`, `AllowIndels`, and `Group` become `seq_id`, `target_seq`, `edit_distance`, `indels`, and `group`. `indels` has the type `bool`, and `edit_distance` has the type `int64`. The column `names` repeats `seqnames`, thus the port does not keep it. A new column, `gene_id`, follows `seq_id`. The column `query` has the R values. The function gives a result for any number of searches with a match (`D-022`). `workers` and the checks of the options are as in `full_search`. `max_seed_edit_distance` must be an integer of 0 or more (`D-023`). |
| `.get_best_match` | `seedmatch.best_match` | Takes the table of counts and returns a `Series` named `best_match` with the index of the table. The ranking and the labels are the R ones. A column that the table lacks is skipped (`D-012`). |
| `SeedMatchR` with `res.format = "data.frame"` | `seedmatch.find_matches` | `target.seq`, `seqs`, `max.mismatch`, `with.indels`, and `fixed` become the arguments of `find_matches` (`Guide.target` makes the target). The search with the R defaults uses `SearchOptions(indels=True)`. The columns `seqnames`, `start`, `end`, and `width` become `seq_id`, `gene_id`, `start`, `end`, and `width`. `match.df` has no argument: `pandas.concat([new, old])` gives the rows of R, with the new rows first. The columns of `sirna.name` (`sirna`, `query`, `TargetSeq`, `EditDistance`, and `AllowIndels`) are not made. `res.format = "granges"` and `"iranges"` have no counterpart. |
| `SeedMatchReport` | `seedmatch.seed_match_report` | `res` becomes `de`, `seqs` becomes `sequences`, and `guide.seq` becomes a `Guide`. `group.name` becomes `group`. The other arguments become the fields of `ReportOptions`, and the defaults are the R defaults. `indel.bool` becomes `indels`, and `allow_wobbles` becomes `wobble`. `log2fc.cut` and `padj.cut` become `log2fc_cut` and `padj_cut`, and `seed.edit.distances` becomes `seed_edit_distances` (a tuple). `fixed` becomes `fixed_pattern` and `fixed_subject`. As in R, the edit distances of `Full`, `18mer`, and `15mer` are not options, and they are 0 to 4. `ReportOptions` raises `InputError` for an invalid field, as `FullSearchOptions` does. A cutoff is an int or a float. A bool, text, and NaN are not valid (`D-024`). The function returns a `SeedMatchReport` (a frozen dataclass) with the fields `report` and `matches`, not a list. The `gt` table (`table`) has no counterpart. In `report`, `Category` and `Group` become `category` and `group`. The category columns and `Total` have the type `float64`, because one column holds counts and a percentage, as in R. `REPORT_CATEGORIES` holds the category names in the R order (`expected.names`). In `matches`, `seqs`, `Group`, `best.match`, and `IN.DESEQ2` become `seq_id`, `group`, `best_match`, and `detected`. `detected` has the type `bool`, not `Detected` or `Undetected`. A new column, `gene_id`, follows `seq_id`. `matches` keeps one row for each sequence, in the order of the set. The counts of `report` are gene counts, and the best match of a gene is the best over its sequences (`D-003`). For a gene with more than one row in `de`, the first row counts, as in R. `de` must have the columns `gene_id`, `log2FoldChange`, `padj`, and `baseMean`. A missing column raises `InputError` that lists the missing columns in sorted order. A `gene_id` column that is not text raises `InputError`. A value column that is not numeric also raises `InputError` (`D-024`). |
